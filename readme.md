## What I have learned

Through this assignment, I learned how to use Git to create commits, inspect commit history, and push changes to a remote GitHub repository.

I learned how to create and switch branches, merge the `for_fun` branch into `main`, resolve possible merge conflicts, and revisit an older commit using detached HEAD.

I also learned how to use Hugging Face to load a pretrained ResNet model and run inference on the MNIST dataset. Because MNIST images do not match ResNet's expected input format, I resized them to 224 by 224 pixels and converted them to three-channel images. I also learned that pretrained ImageNet models can perform poorly on MNIST without fine-tuning.

Finally, I learned how to use `.gitignore` to prevent virtual environments, datasets, caches, and model weights from being committed to the repository.
